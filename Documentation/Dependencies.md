# Dependencies

**i85 Simulator & IDE** is developed using Python and customtkinter.  
The entire simulation and the UI is written using python.  
The following packages are used.

- Python 3.13.2 (64-Bit)
- customtkinter
- pygments
- tkinter (Required by customtkinter)
- Pillow  (Unused dependency, may be removed later)
- tklinenums
- CTkCodeBox (Modified to support dynamic sizing of line numbers)
- CTkTable
- pywinstyles (Unused Dependency, will be removed later)

---
# External Binaries
